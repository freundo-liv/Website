# Website
For a company, I used learned and used html and css to create a website to display the various services avilable. 
The website subtotals the services you select and has a reset button for when you want to start over. Furthermore, 
I integrated a js file to incorporate a fade-in effect for the selected services. I removed the website title and 
left out the names of the varioud services to comply with the company's privacy regulations. For the full project report, click [here](https://github.com/freundo-liv/Website/blob/main/Website%20Project%20Report.pdf) or go to my [LinkedIn.](https://www.linkedin.com/in/olivia-freund-91a197252/)
